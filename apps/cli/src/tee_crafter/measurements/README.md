# Launch-measurement registry

Auto-generated by `tee-crafter internal bake-ami`. One JSON file per baked
image, laid out as:

```
measurements/<tee-platform>/<sanitized-image-id>.json
```

Each file records the TEE launch measurement (`measurement` for AMD SEV-SNP,
`mrtd` for Intel TDX, `pcr0` for Nitro, `mrenclave` for SGX) of the image so
that `deploy` can pin it automatically — no manual capture step. Sealed
`--secrets-env` and BYOK release fail closed when a requested image has no
entry here (override with `TEE_CRAFTER_ALLOW_UNPINNED_MEASUREMENT=1` for dev).

Do not hand-edit these files; re-bake to regenerate. See `docs/measurements.md`.
